## 二、为什么这么分（三条口径）

1. **一族一个「一眼」**：斩击＝斜线、射击＝直线、爆炸＝圆、雷电＝折线、重力＝向内、治愈＝向上。
   形状本身就是分类，颜色只做加强 —— 色弱的人靠形状也读得出是哪一类。
2. **不做 canvas、不加图片**：每族都是十来二十个 `<i>`（transform + opacity + filter），
   单次节点上限 40，`fx` 一清就整棵卸载（回放那一段本来就按条挂载/卸载）。
3. **`prefers-reduced-motion` 下退化成「闪一下」**：一族只剩一层，150ms 淡入淡出、不位移、不抖屏。

## 三、登记表在哪

`src/views/BattleFx.tsx` 的 `FX_TABLE`（按 skillId 点名）与 `BY_NAME`（按招式名的词根猜族）。
新招式优先按词根落族；词根也不像的，才在 `FX_TABLE` 里点名 —— 表是唯一的事实来源，
`Battle.tsx` 里只有一处 `familyOf(...)` 的调用。

## 五、演出强度（标准 / 减弱）与收掉的手法

2026-09-19 主人两次收话后的定版：

| 手法 | 标准 | 减弱 | 说明 |
| --- | --- | --- | --- |
| 命中定格 hitstop | ≤ 55ms | 0 | 节奏，不是运动 —— 保留在标准档 |
| 震屏 | 1px / 2 帧 | 无 | 幅度与帧数写死在 Battle.module.css 的 `shakeSoft` |
| 整屏推近 / 旋转 | **不做** | 不做 | 眩晕来源，已撤（`data-cam` 与相机 keyframes 一并删掉） |
| 全屏白闪 | **不做** | 不做 | 改成效果层里的**局部高光**（径向、半径受限） |
| 暗角 | 幅度减半（26%） | 无 | |
| 残影 / 环 / 碎点 / 折线 | 有 | 无（只剩一层光带） | 减弱档保留「一帧形变 + 一层余光」，形状与颜色仍在 |

玩家入口：**作战屏 C 菜单里「演出强度」那一枚**（Z 键切换），存 `zts-fx-level`；
没手动选过就跟随系统 `prefers-reduced-motion`。

## 六、验收取样口径（时间轴三帧）与「命中核」补强（2026-09-19 二审之后）

上一轮截图取的是**尾巴帧**（效果快散时），看起来只剩一圈淡环 —— 那是取样错，不是设计强度。
现在改成**时间轴采样**：每手在 t≈15% / 45%（命中）/ 75% 各定格一帧（`?fx=all` 预览台 + 探针把每层
`animation-delay` 加负偏移并 `animation-play-state: paused`，命中核那层伪元素用 `[data-froze]` 钉住）。

同时按「命中那一帧要有东西」补强了三处（都是纯 CSS，不加节点）：

| 补强 | 做法 | 为什么 |
| --- | --- | --- |
| 命中核 | `::before` 径向实心核光，20% 烧到最亮、44% 开始退；斩/射改成**细长的一条**而不是圆 | 上一版命中帧只剩环与碎点，读不出「打实了」 |
| 冲击环 | 边宽 2→4px | 扁环在白底上太细，一缩就看不清 |
| 碎裂片 | 7→10px + 本色 drop-shadow | 碎片要有实体感，不是灰点 |

口径不变：镜头语言（推近/旋转/整屏位移）不做；全屏白闪不做；震屏 1px/2 帧；
减弱档只留一帧形变 + 一层余光。
