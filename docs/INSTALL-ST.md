# 停滞观测终端 · 安装到 SillyTavern

本目录是一份完整的 **SillyTavern 网页扩展**（世界观/剧情卡前端）。
`manifest.json` + `index.js` 即扩展本体；`offtext/` 是随卡发布的离线原文数据文件。
**不含任何接口密钥**，也不需要你为它配 key。

## 你需要的

- **SillyTavern 1.18+**（扩展以 ESM 注入主页面，老版本不支持）。
- 在酒馆里已配置**至少一个可用 AI 后端**（OpenAI/Claude/本地…任意），并选好预设。
- `config.yaml` 里 `extensions.enabled` 为 `true`（1.18 默认开启）。

## 安装（二选一）

### 方式 A：把整目录放进扩展目录

把本 `zts-terminal/` 目录解压/复制到酒馆的扩展目录，最终路径应为：

```
<ST>/data/<你的用户>/extensions/zts-terminal/
  ├─ manifest.json
  ├─ index.js
  ├─ index.css
  ├─ INSTALL.md
  └─ offtext/…
```

然后**刷新酒馆页面**（扩展随激活自动加载，无需额外开关）。
扩展管理页里出现「终末停滞委员会 · 停滞观测终端」即成功。

### 方式 B：从源码构建后安装

见仓库根 `README.md`（`npm ci` → `npm run st:install`）。

## 开始游玩

1. 页面右下角浮动按钮 **「停滞观测终端 进入」** → 打开终端全屏壳。
2. 开屏**长按指纹**完成委员认证（约 1.5 秒，只作仪式感，不联网、不存证）。
3. 进 **剧情推进**，点 **在线推演**。
4. 首次若提示「尚无推演锚点」：去 **终端设置** 的「酒馆宿主模式」面板，点 **一键就绪**
   —— 会自动取你酒馆里的一名现有角色作为「推演锚点」并接通对话；也可以下拉**指定角色**
   或点 **另起一段新对话** 从头开一段干净剧情。
5. 之后每次推演，AI 都以**该锚点角色的当前对话**来生成——你的预设、已激活世界书、
   角色卡全部照常生效。收束事件会按事件卡逻辑写入本卡记录（不开酒馆的“自动摘要”等即可）。

> 若酒馆里一个角色都没有：先回酒馆导入/新建一张角色卡再一键就绪。
> 本卡不读取、也不替你把密钥写进任何文件；短信通道在宿主态暂不接入（独立版可用）。

## 进度存哪 / 会不会污染你的酒馆

- 卡内记录、事件推进、已解锁档案、词条库：存酒馆同源浏览器的
  `localStorage(zts-*)` 与 `IndexedDB(zts-lore / zts-terminal-store)`。
- 推演回合会出现在锚点角色的酒馆聊天里（由 generate 正常投递并存档）——
  这正是“用你自己的预设与世界书跑剧情”的机制；导演上下文按回合注入、回合结束即清空。
- 词条库/备份导出**绝不含密钥**。
