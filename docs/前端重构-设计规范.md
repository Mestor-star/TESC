# 前端重构 · 设计规范

> 2026-11 完全重构（m03825）的唯一口径。旧页面只作内容与逻辑参考，版式重写。
> 颜色/间距/字号只准取 `src/styles/tokens.css` 变量；本文写「怎么用」，不写新值。
> 与 `视觉规范-洁白科幻极简.md` 冲突时：**本文优先**（重构后的新骨架），旧文仍管配色与禁用清单。

## 0. 一句话

一座**冷白全息观测终端**：左栏是终端机位，中间是舞台，右上是操作台。留白是主结构，动画是仪式感，不是装饰。

## 1. 三层骨架

```
┌────────┬──────────────────────────────────────────┐
│ rail   │ topbar  56px   状态 · 时间 · 通知          │
│ 78px   ├──────────────────────────────────────────┤
│ 悬停   │ sectionTabs（仅图鉴三页签时出现） 40px     │
│ 展开   ├──────────────────────────────────────────┤
│ 252px  │ stage：整块换页，只有这一层做转场           │
└────────┴──────────────────────────────────────────┘
```

- rail 收起态只有图标 + 极短标签（两条汉字以内），悬停/键盘 focus-within 才展开覆盖主区，**不挤压正文**（`position` 覆盖 + `z-index`，仅 ≥861px）。
- 主区永远一屏，滚动只发生在页面内部的指定列；页面自身不出现第二条滚动条。
- 页面内边距：桌面 `28px 32px`，≤1120 `22px 24px`，≤860 `16px 14px`。

## 2. 终端主页（FGO 式）

- 中轴：角色立绘，底对齐，高约 `min(72vh, 640px)`，不描边、不投影、不加光。
- 立绘左上：三层信息——编号（11px/0.14em）→ 名（28px/600）→ 一行身份（13px/--ink-mute）。
- 左下：`切换 ‹ 03 / 12 ›`，点击立绘本体或该行都能换人，只轮换已遇见者；换人只做 220ms 淡入 + 6px 上浮。
- 右侧动作簇：五项竖排，右对齐于 `right: 9vw`，行距 18px；收起态整体向右收 24px、透明度 0.55；指针靠近簇 40px 或 Tab 进入即展开（240ms）。
- 每项 = 序号（11px 等宽）+ 汉字（20px/600）+ 英文（10px/0.18em，--ink-faint）；悬停时序号变 --steel、右侧出现 18px 细横线。
- 背景幽灵字：动作英文名，`clamp(96px, 18vw, 260px)`，色 `--bg-3`，`z-index:0`，不透明度 1，**不做渐变**。
- 顶部读数条保留 `data-dash-stats` 六格与 `data-dash-next`（冒烟依赖）。

## 3. 颜色与材质

- 底 `--bg-0`；承载面 `--bg-1` + 1px `--line-2`；内嵌条 `--bg-2`。一屏最多三档白。
- 强调只有 `--steel`（底/线）与 `--steel-deep`（字），一屏 ≤3 处。
- `--red` 只用于危险/冲突，`--amber` 只用于待办提醒，`--violet` 只用于角色侧，`--jade` 只用于成功。
- 零圆角（`--radius: 0`），pill 只给徽标；静态面无影；浮层才用 `--shadow-3`。
- 禁止：渐变背景、毛玻璃、彩色光晕、扫描线、网格底纹、字面值颜色。

## 4. 字阶（只这七档）

11（标签/角标，字距 .08em）· 12（密排）· 13（列表/按钮）· 14（正文基准）·
16（小标题/读数）· 20（区块标题/动作项）· 28（页面 h1/角色名）。
字重只 400 / 600。数字走 `--font-mono` + `tabular-nums`。

## 5. 组件语汇

| 组件 | 规格 |
| --- | --- |
| 页头 | 左：kicker(11px 英文) + h1(28px) + 一行说明(13px --ink-mute)；右：1–2 枚次要动作。底部 1px `--line`，下留 24px |
| 读数条 | 一行横排，格与格之间 1px 竖线；值 16px/600 mono，键 11px --ink-faint |
| 列表行 | 高 44px，1px `--line` 分隔，悬停 `--bg-2`；左 34px 图标位，右 11px 角标 |
| 页签 | 高 34px，仅激活项底部 2px `--steel`；未激活 --ink-mute，悬停 --ink |
| 主按钮 | 高 38px，`--steel` 实底 + 墨字；悬停 `translateY(-2px)` + `--offset-sm` |
| 次按钮 | 透明底 + 1px `--line-2`；悬停边 `--line-3` |
| 空态 | 居左，一行 13px --ink-mute + 一行 11px --ink-faint 说明，不给插图 |
| 角标 | 2px pill，11px；未读用 `--red` 实底白字（唯一允许的彩底白字） |

## 6. 动效

- **换页三向**：前进 `translateX(28px) → 0` + `rotateY(-2deg)` + 淡入；返回反向；同级纯淡入。460ms，`cubic-bezier(.22,1,.36,1)`。只动 stage 一层，rail 与 topbar 不动。
- 页内元素不做逐项 cascade，最多整体延后 40ms。
- 悬停 160ms、展开 240ms、换人 220ms。
- `prefers-reduced-motion: reduce` → 全部 1ms 直切。
- 禁止：超过 520ms 的常驻动画、循环呼吸（危险态除外）、视差、缩放超过 1.02。

## 7. 响应式

| 宽度 | 变化 |
| --- | --- |
| ≥1121 | 完整三栏，rail 悬停展开 |
| 861–1120 | 主页右侧动作簇收到 `right: 5vw`，立绘高 `60vh` |
| ≤860 | rail 变底部横条（56px 图标），主页改纵向：立绘 48vh、动作簇变两列网格、幽灵字降到 72px |
| ≤720 | 所有两栏页面单栏化，表格横滑 |

## 8. 验收清单

1. 只用 tokens 变量，无字面值颜色/字号/圆角；`backdrop-filter` 0 处。
2. 键盘：Tab 可走完 rail、动作簇、页签；焦点环 `outline: 2px solid var(--steel)`，`offset 2px`。
3. 三向转场在 Chrome/Edge 各跑一次，前进/返回/同级方向正确。
4. `prefers-reduced-motion` 下无位移动画。
5. 冒烟把手全部保留：`data-dash-stats`、`data-dash-next`、`data-hub-action`、`data-codex-tab`、`data-mission-tab`、`data-view-stage`。
6. `npm run lint` 0 error、`npx tsc -b`、`npm run build` 全绿。
