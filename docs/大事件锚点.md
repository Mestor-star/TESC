# 大事件锚点（原文考据）

> 目的：主人要「剧情更不固定、更自由，但**那几个大事件仍然会发生**」。所以本文件只做一件事：
> 把「不可动摇的大事件」从原文里考据出来，并划清**哪一部分可以变**。
>
> 本文只写 docs/大事件锚点.md，未改 src/**、public/**、scripts/**、.canon/**。

## 0 · 口径与证据

**证据来源（按可信度排序）**

| 层 | 路径 | 用途 | 约束 |
| --- | --- | --- | --- |
| 原文切片 | public/offtext/*.txt（v1-1 … v6-x、s1-x，57 段 + index.json） | 引文与行号的**唯一**出处 | 逐字引用，**摘句 ≤60 字/处** |
| 整卷原文 | .canon/<卷>/<话>.txt | 定位与复核（只读） | 同上；本文不整段搬运 |
| 结构化骨架 | src/data/timeline.ts（57 事件）、src/data/scenes.ts（openTag 的「卷·话」标注）、src/data/eventnotes.ts（35 条逐字摘录） | 事件 id ↔ 卷/话 的对应 | 是**二手整理**，不作原文出处 |

**方法**：先以 timeline.ts + scenes.ts 的 openTag 建立「事件 id ↔ 卷/话」骨架，
再逐卷回到 public/offtext/ 读序章 / 中段 / 结尾三段以上，用「关键词 → 行号」定位每个
候选锚点，**只有在原文里找到那一击的证据才写进本文**。实际读过（行号为切片内行号）：

- v1：v1-1.txt L1–60（序章开篇）、v1-3.txt L285–304（销毁宣判）、v1-9.txt L880–937（契约缔结）
- 各卷末切片结尾：v1-9 L1582–1592、v2-9 L390–400、v3-9 L3748–3758、v4-8 L2830–2840、
  v5-7 L2630–2640、v6-8 L1936–1946、s1-7 L270–280
- 其余锚点：关键词命中行（下文每条都带）

**三档分类**（后文与 §9 一致）

- **真锚点**：世界状态 / 人物关系的**不可逆变化**。可以换衣、换在场者、换代价，但**不能不发生**。
- **准锚点**：必须留下「残渣」（情报、关系、名声、物品），但**载体可以整体替换**（换地点/换人/换任务外衣）。
- **细节 / 过场**：气氛、日常、单个任务外衣。可以完全跳过、合并、改写。

**一个必须先说清的边界**：原文里「**锚点发生 ≠ 主角在场**」。多数锚点是**世界侧**事件
（入侵、会议、巨匠的动向），主角缺席时它照旧发生，只是**情报与关系后果**变了。这正是
放开自由度最省事的一条缝：不必逼玩家去做，只需逼世界去变。

## 1 · 第 1 卷（船与影 → 钢铁的新娘）

### 1.1 卷级脊梁（4 条）

**A1｜女神神殿：露娜登场，「转生之门」骗局破裂**（v1-2）

- 事件：心叶溺死后被女神召唤，丝线人偶「露娜」侍奉他；他识破转生之门是吞人的「灵魂蓄积器」，
  拒绝一切神授能力——「我只是想度过普通的青春而已」。
- 不可省：这是**露娜这个人存在的入口**，也是「心叶＝拒绝特殊性的普通人」这一母题的源头；
  没有它，v1-3 的审判、v1-9 的契约都失去对象。
- 出处：public/offtext/v1-2.txt#L403「那是仿佛肉块蠕动的声音。顺着声音望去，是那扇转生之门。」
  ；同 #L521「也就是说，那就是灵魂蓄积器TM对吧！」；卷1/序章〈船与影〉末段。
- **可变量**：在场者（原文是恋兔队破门 → 可换成委员会、或单独一人）；过程（谁拆穿、露娜是否被
  压碎）；代价（露娜的受损程度）；关系后果（初遇印象的好坏）；情报（是否知道「神」是什么）。
- 触发：**时间推进**（第 0 日死亡 → 强制进入「第二次人生的入口」）。
- 绕开时：不可跳过。若玩家拒绝逃离神殿，改为「装置自行启动、被强行推出」——关系后果偏移
  （露娜的初遇变成「被拖累」）。

**A2｜异端审问室：两人被收留（委员会成立）**（v1-3）

- 事件：露娜以「境界领域商会制造的反现实实体」受审、判即刻销毁；心叶扑上去搏斗、断骨夺枪，
  靠读心伪装「预知未来」；会长艾莉芙裁定两人以「苍之学园 体验入学」名义留下，由弗恩监视。
- 不可省：**舞台与归属在此确立**——此后所有卷的「苍之学园 / 终末停滞委员会」身份、以及
  艾莉芙与弗恩这两个长期关系，全部挂在这一击上。
- 出处：public/offtext/v1-3.txt#L289「——我在此宣判：对你，执行即刻销毁处分。」
  ；同 #L347（终末潜力 Stage3「成长」）；卷1/第1话。
- **可变量**：心叶的搏斗方式与受伤部位（原文断锁骨）；「预知未来」这个假底牌的编法；在场骑士；
  裁定的措辞与艾莉芙的态度；露娜是否开口自辩。
- 触发：被捕 / 进入学园审问（可由玩家行为提前或延后一天）。
- 绕开时：若玩家**不护露娜**，改为「露娜被带走、由研究所接管」，随后 v1-9 的契约前提变成
  「夺回」。允许偏移，**不允许「两人没被绑在一起」**。

**A3｜深海异界：守护者与泥塑面目的来源**（v1-8）

- 事件：心叶与梅芙乘八脚马潜航误入 R 值崩坏的异界，见到数千亿年前旧人类留下的巨型机械
  「守护者」，它正把被时间冻结的旧人类粉碎成「泥塑面具」以求复活；露娜以丝线「心血来潮」现身。
- 不可省：把「泥塑面具」这个贯穿全书的意象**接到了旧人类身上**；同时确立 v1 的主敌与
  「终末＝失控的旧文明遗产」这条设定线。
- 出处：public/offtext/v1-8.txt#L407「那家伙，是以前人类的『守护者』。」；卷1/第7–8话。
- **可变量**：潜航组合（原文梅芙 → 可换小柴/恋兔/独自）；如何脱出；露娜是否现身；
  是否解放天幕下被缚的旧人类；情报的获取量。
- 触发：玩家**主动接受潜航任务**（乘八脚马），或时间到第 7 日被派遣。
- 绕开时：玩家不下潜 → 由梅芙单走，玩家只在通讯里参与；真相情报延后到 v1-9 由露娜口述。

**A4｜黄金狮子与「使用者契约」**（v1-9）

- 事件：心叶为护露娜被万针穿身濒死，露娜以己命为他缝伤输血，在「我可以坚持到最后吗」「可以哦」
  中缔结使用者契约，解放本源终末「黄金狮子」；幸存的守护者化为「死骸机关之神」冲向现实，
  被恋兔光一记「樱之残影」当空击落。尾声：露娜迁入宿舍，唤他「我的小主人」。
- 不可省：**全书关系的地基**——「使用者 / 小主人」这个称呼与隶属关系从这里开始，一直到 v6 都不再改；
  同时「死骸机关之神在现实上空被打掉」这件事让**恋兔的战力被世界看见**，直接催生 v2-1 的暗杀名单。
- 出处：public/offtext/v1-9.txt#L891「我……可以，坚持到最后吗。」；#L931「使用者契约完成。」
  ；#L993【No.8288「黄金狮子」】；#L1145【No.228-B「死骸机关之神」】；卷1/第10–12话＋尾声。
- **可变量**：代价形态（心叶是否濒死）；契约台词；在场者；**谁击落死骸机关之神**（原文恋兔，
  可换成委员会联手）；露娜是否「燃烧灵魂」；尾声的住处安排。
- 触发：守护者群压制 → 露娜提出「还有一个唯一的方法」→ **玩家的决断**（接受 / 拒绝）。
- 绕开时：拒绝契约 → 露娜自行发动（以自身为代价），锁仍生效但关系带上愧疚底色。
  **不允许无代价通关**。

### 1.2 角色线（**不是锚点**）

## 2 · 第 2 卷（转校生 → Finish Line）

### 2.1 卷级脊梁（4 条）

**B1｜匿名者集会：暗杀名单**（v2-1）

- 事件：「匿名者集会」议定动手之日，绯发少女指出新入队的言万心叶「似乎具备预知未来的能力，

- 不可省：给全书装上了**「有组织在猎杀终末持有者」**这条持续威胁，也是巨匠一方第一次以
  集体面目出现（v2/v4 的敌手链从此有主）。
- 出处：public/offtext/v2-1.txt#L25「……『言万心叶』所持有的终末，似乎具备预知未来的能力。
  必须优先排除。」；卷2/序章。
- **可变量**：集会成员构成与发言者；是否有内鬼；**玩家能否获知**（这是最该放开的：可以是「不知道」）；
  绯发少女是否亲自出面。

**B2｜转校与 noapusa 觉醒**（v2-2）

  ；同 #L825「这就是，我的心之形。」；卷2/第2话。
- **可变量**：试炼内容；觉醒时的梦与「白翼少女」的形象；谁在场；**觉醒早晚**。
- 触发：玩家**主动接受模拟装置试炼**（入学手续），或实战中被逼出来。
- 绕开时：可延后到 v2-4 竞技祭实战中觉醒；**但必须在 v3-9 之前到手**。

**B3｜第 6 区远征（恋兔队成军）**（v2-3）

- 事件：艾莉芙向恋兔坦白「为了他才当上学生会长」，把心叶托付给她；恋兔队（恋兔、心叶、露娜、
  梅芙、小柴，外加被卷进来的吴诗涵）乘银河铁道前往第 6 区参加三大学园「天空竞技祭」代表战。
- 不可省：**舞台换到 Corporations**（v2 后半与 v6 的组织关系都从这里起）；恋兔队这一编制在此定型；
  艾莉芙的动机公开。
- 出处：public/offtext/v2-3.txt#L11「据说在下次的天空竞技祭上，有人策划了对你的暗杀计划。」
  ；同 #L159（关注度＝整个弗尔克图斯）；卷2/第3话。
- **可变量**：出征名单（谁去）；交通与路线；是否全员同意；艾莉芙坦白的对象。
- 触发：会长下令 / 玩家接受远征。
- 绕开时：玩家拒绝 → 以「被点名代表」强制征召（暗杀风险不可回避）。

**B4｜Finish Line：巨匠现身、魔王被告白与被吞**（v2-8）

- 事件：凯特琳借沙姆希尔贴纸把恋兔传至荒野，会场落下「二级天使・百翼」，**巨匠首次正面现身**
  并吞下黑之魔王，又以石化语钉住心叶与梅芙；黑之魔王脱困后当场告白强吻，随即与巨匠双双失踪；
  恋兔断臂反杀全场，一句「我就是人类」终结战争，凯特琳被擒。
- 不可省：整整三卷的因果都挂在这里——①巨匠成为魔王与心叶的共同仇敌（v4-1 之死、v6 线之人链）；
  ②魔王与巨匠**双双失踪**，这是 v3–v4 她「游离于主线之外」的唯一解释；③魔王强吻告白（她线的前提）；
  ④凯特琳被擒（v3-2 越狱的因）；⑤「我就是人类」是恋兔的人设锚。
- 出处：public/offtext/v2-8.txt#L361（巨匠自报名号）；同 #L291「那是第二次吻。」；卷2/第10话。
- **可变量**：谁与凯特琳对决（原文恋兔）；露娜/蕾雅的救援方式；**告白是否被旁人听见**；
  巨匠是否被重创；「双双失踪」的形态（各自遁走 / 一起消失 / 被第三方带走）。
- 触发：竞技祭代表战推进到「大将战」＋凯特琳的埋伏（时间＋地点双条件）。
- 绕开时：玩家不参赛 → 恋兔单走，魔王告白挪到「战后重逢」；**巨匠现身不变**（它是世界侧）。

## 3 · 第 3 卷（永田町 → 星鲸）

### 3.1 卷级脊梁（5 条）

**C1｜未知威胁对策会议（异厅与苍学园结盟）**（v3-1）

- 事件：日本侧检测到巨型传送门预兆，异厅厅长天草清麿向要员说明这是远超文明规模的入侵；
  被收容的黑之魔王凭「身为妻子的特权」促成向苍之学园求援。
- 不可省：**官方与学园的同盟**在此成立（v3-7 的全次元战争、v4 之后的地球舞台都靠这条线）；
  黑之魔王的政治位置公开化。
- 出处：public/offtext/v3-1.txt#L83「凭借身为妻子的特权，我肯定可以促成这场谈判的哦（耶）！」
  ；卷3/序章。
- **可变量**：心叶是否列席；魔王是否亲自出席（可换代理人）；会议结论的强硬程度；谁被派去求援。
- 触发：时间推进（检测到传送门预兆）。
- 绕开时：世界侧不可绕开；玩家不在场 → 只以「事后简报」呈现，情报缺口由后续补。

**C2｜真相：死灵次元 → 铁之心脏 → 星鲸**（v3-3）

- 事件：被捕的侦探「废道昏暗」全盘托出——死灵次元的尸兵瞄准上野不忍池底的机密终末「铁之心脏」，
  一旦被毁，「星鲸」的行进路线将改向樱次元致其全灭；她为救故乡而背叛侦探协会。
- 不可省：**敌人为什么打、打哪里、打坏的后果**全在这段；没有它，v3-7 的防线布置与 v3-9 的登箭
  都失去理由。
- 出处：public/offtext/v3-3.txt#L69【No.1000「铁之心脏」】——Stage 1「始源」；同 #L81
  「简单来说——铁之心脏的作用是『将我们的次元，从其他次元的威胁中隐藏起来』。」；卷3/第2话。
- **可变量**：审讯者是谁；**玩家是否旁听**（可完全不知情）；情报的完整度（可拆成两三片）；
  侦探的结局。
- 触发：逮捕侦探后，玩家选择「听 / 不听」。

## 10 · 结论：最硬的 5 个锚点

1. **v1-9 黄金狮子与使用者契约** —— 「使用者 / 小主人」这个隶属关系一旦成立就再没改过，
   它同时把「恋兔的战力」送上了世界舞台（v2-1 暗杀名单的因）。
2. **v1-3 异端审问室的裁定** —— 「我们是谁、属于哪里、谁在盯着我们」全部在此定案，
   后面六卷的所有行动都以「苍之学园 / 委员会的一员」为前提。
3. **v2-8 Finish Line** —— 一条锚点同时钉住四件事：巨匠成为共同仇敌、魔王与巨匠双双失踪、
   魔王告白、凯特琳被擒。**拆得越开越危险**。
4. **v4-8 沉默之律** —— 直接改世界法则（此国再无时间旅行 / 无人能操纵人类），
   并把「线之人」立成 v5–v6 的长期敌手。
5. **v5-5 世界即试炼** —— 把「日常」本身判定为拟似世界；此后每一段日常都带着被拆穿的可能，
   这是全套设定里最不可撤回的一刀。

> 次席（结构最硬、但只作用于单卷）：**v6-1 决斗契约**——全系列唯一明文的期限与地点
> （一个月后 / 第零区尸肉神殿 / 四名协力者），也是玩家自由度最高的一处（四名是谁由玩家定）。

## 11 · 最该先改的 3 个「过度强制」点

1. **v1-9 的 lock: [{ char: 'luna', value: 100 }]**（timeline.ts:115，相关注释在 111–114 行）
   把关系锁成满值，「此后无论说什么都不会再低」。这不是原文事实，是终端的模拟选择；它直接抹掉了
   玩家在露娜线上的全部表达空间。**建议**：锁保留（契约确实不可逆），但改成「下限 85 + 只增不减」，
   或「锁的是称呼与隶属，不是好感读数」。
2. **57 事件串成一条 order**：timeline.ts 用 order + unlock: true 把事件排成唯一路径，连 day 都排到了
   「第 0 日…第 10 日」。原文并没有按日标注（v1 的「第 8–9 日」空缺即是证据，见 §1.3）。
   **建议**：order 只保留作**卷内锚点的先后**，把准锚点与细节摘出 order，改为按 time / at / act
   谓词触发；day 从「硬排期」降级为「默认节奏参考」。
3. **cast（现场在场名册）被当硬约束**：每个事件都把在场者写死（v1-5 必须是蕾雅与玛吉娜、v2-8 必须
   是那一长串），于是「带谁去」这一整类自由选择被数据层直接否定。**建议**：cast 改称 castDefault
   （原文在场者，用于还原与提示），另加 castNeed（锚点成立的最低条件，例如 v1-3 只需
   「露娜＋艾莉芙」）。**验收入口应与 castNeed 对齐，而不是与 cast 对齐。**
