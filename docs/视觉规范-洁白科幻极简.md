# 视觉规范 · 洁白科幻极简

> 本仓的唯一视觉口径。所有 `.module.css` 都从这里取值：颜色、间距、圆角、字号只准走
> `src/styles/tokens.css` 的变量；本文只写「怎么用」，不写新值。改动前先读第 10 节禁用清单。

## 1. 底色与层级（哪几档白）

| token | 值 | 只准用在哪 |
| --- | --- | --- |
| `--bg-1` | `#ffffff` | 承载面：卡片、面板、输入框、浮层。**纯白是主角** |
| `--bg-0` | `#f2f6ff` | 页面底。只作整屏衬底，不刷在卡片上 |
| `--bg-2` | `#eef3fd` | 次级区块：表头、悬停底、内嵌条、代码块 |
| `--bg-3` | `#e2eaf9` | 仪表轨道、禁用块、占位骨架 |
| `--bg-4` | `#cfdcf1` | 深一档分隔（少用，一屏至多一处） |

- 一屏**最多三档白**（底 + 承载 + 次级）。第四档出现就说明层次没靠边分清。
- 页面底是**纯色**，不叠径向光斑、不叠网格、不叠扫描线。
- 面板层次靠**边**分，不靠影分：静态卡片无影、无渐变。

## 2. 描边（粗细与色）

- 全站只有 **1px** 一种线宽；2px 只允许「激活态左记号」一处用途。
- `--line`：同族分隔线（列表行、区块内）。
- `--line-2`：**容器默认边**（面板、输入框、按钮）。
- `--line-3`：只给可交互件的悬停/聚焦，不刷静态面。
- 禁止 >2px 边框、禁止彩色边框当装饰（状态标签的彩边除外，且必须是 `color-mix` 淡边）。

## 3. 强调色（只准蔚蓝）

- 唯一强调色：`--steel`（底/线/填充）与 `--steel-deep`（字/图标）。
- **只准出现在这几类元素**：① 主按钮；② 导航/标签页的激活态；③ 可点文字与链接；
  ④ 焦点环与选中框；⑤ 关键读数与进度填充；⑥ 页头那一条蔚蓝记号。
- 其余四支（`--red` / `--amber` / `--jade` / `--rose` / `--violet`）**降级为语义状态色**：
  只出现在状态标签、读数、仪表条、图标、私密档案那一页；**不作装饰、不进渐变、不当标题色**。
- 本色当底时，压在上面的字一律 `--on-accent`（墨），不配白字。
- 一屏里蔚蓝记号**不超过三处**。第四处开始就变成了「科技感」，不是「极简」。

## 4. 圆角与阴影（上限）

- 圆角：`--radius: 0`、`--radius-sm: 0`；`--radius-pill: 2px` **只**给徽标/芯片/状态签；
  真圆只准 `50%`（点、头像、序号）。新代码不许写字面圆角。
- 静态面**无影**。层次靠 1px 边与留白。
- 可交互件悬停：实心位移垫片 `--offset-sm`（`0 3px 0`，零模糊）＋ `translateY(-2px)`。
- 唯一柔影 `--shadow-3`，**只给浮层**（modal / toast / lightbox）。
- 禁止：彩色柔影、发光、`drop-shadow`、`0 0 Npx` 光晕、文字重影。

## 5. 字阶（只这七档）

| 档 | 字号 / 行高 | 用途 |
| --- | --- | --- |
| 标签 | 11px / 1.4，字距 0.08em | 角标、kicker、计数、键名 |
| 密排 | 12px / 1.5 | 次要说明、表头、时间戳 |
| 小正文 | 13px / 1.5 | 列表行、按钮、表单标签 |
| 正文 | 14px / 1.6 | 段落、输入框、卡片正文（全站基准） |
| 小标题 | 16px / 1.4 | 卡片标题、读数数字 |
| 标题 | 20px / 1.3 | 区块标题、弹层标题 |
| 大标题 | 28px / 1.2 | 视图 h1、终端品牌 |

- 行高只允许 1.2 / 1.3 / 1.4 / 1.5 / 1.6。
- 字重只有 **400 / 600** 两级。600 只给标题、按钮、读数键名；其余 400。
- 大号数字走 `--font-mono` + `tabular-nums`，字距 0。

## 6. 留白（4px 基数）

- 只用 4 / 8 / 12 / 16 / 24 / 32。行内间隙 4–6，控件内边距 8–12，
  卡片内 12–16，区块之间 24–32，页面内边距桌面 24–26、手机 14–16。
- 留白是**主结构**：宁可少放一张卡，不要挤满。空白处不填底纹。

## 7. 层级与状态

- 三层：页面底（`--bg-0`）→ 承载面（`--bg-1` + 1px `--line-2`）→ 内嵌条（`--bg-2`）。
- 状态只靠**文字 + 一支语义色**表达，不加第二层色块、不加动画强调（`pulseGlow` 只留危险一档）。
- 浮层：遮罩 `--ink` 62%，面板 `--bg-1` + 1px 边 + `--shadow-3`。

## 8. 图标

- 线宽与描边一致（Phosphor regular），尺寸 16 / 20 / 24。
- 颜色跟随文本色；不许给图标上渐变、上光晕。

## 9. 动效

- 只做位移与淡入，时长 200 / 300 / 420ms，缓动 `--ease-out`。
- 不做扫描线、闪烁、循环呼吸（危险态除外，且只许 `pulseGlow`）。

## 10. 禁用清单（出现即返工）

1. **大面积渐变**：页面底径向光斑、卡片内青→绯斜切、按钮双色渐变、面板顶部渐隐。
   （**唯一放行**：功能性遮罩渐变 —— 图片边缘渐隐、滚动列表贴边淡出、横滑内容的 `mask-image`。它遮的是内容，不是装饰。）
2. **毛玻璃**：`backdrop-filter` 全站保持 0 处。
3. **彩色阴影 / 发光 / 文字重影**：`--duo-shadow` 已置 `none`，别再写字面 `text-shadow`。
4. **超过两级的字重**：700 / 800 / 900 一律视为错误。
5. **装饰性分隔线**：三色分段、斜纹底纹、网格、扫描线、四角括号。
6. **渐变仪表条**：meter 填充一律实心单色。
7. **字面值颜色 / 圆角 / 字号**：必须走 token 或本文表中的档位。
8. **>2px 边框**、**>2px 的彩色左记号**、**彩色 box-shadow 光晕**。

## 11. 具名例外（写死在这里，别再扩张）

- `.hazard` 警戒带：只作 ≤5px 的信号条（重复斜纹是「危险」的语义，不是装饰）。
- `--pv-*` 四支：开场 PV 标题卡按原片取色，逐像素保留；黄字是暗纹，不追对比度。
- `--rose` 一系：只在私密档案那一页，翻过去才出现。
- 私密档案与作战屏的既有读数色不受第 3 节限制，但同样不许上渐变与柔影。
- `TitleCard` 的 RGB 分离文字影与 `blur` 入场：那是 PV 收尾标题卡的**原片节拍**
  （7 帧的一次性动画），不是常驻装饰，保留。
