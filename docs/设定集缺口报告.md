## 1. 统计方法与可复现口径

所有数字都由 Node/PowerShell 直接读源码文本算出（**不 import TS、不跑构建**），任一条都能用同样命令复现：

| 指标 | 口径 | 复现命令（仓库根执行） |
| --- | --- | --- |
| 事件数/卷 | `timeline.ts` 中 `^\s*id: '(vN|s1)-\d+'` 的条数 | `Select-String src/data/timeline.ts -Pattern "^\s*id: '(v\d|s1)-\d+'"` |
| 事件段数/卷 | `scenes.ts` 中 `'<id>': {` 键数 | `Select-String src/data/scenes.ts -Pattern "^\s*'(v\d|s1)-\d+':"` |
| 引文覆盖率 | 段内是否有 `quote:`；逐字判定＝把引文与 `.canon` 全文都去掉空白与 `「」『』，。、！？…—·` 后做**子串包含**检查 | 见 §1 附脚本 |
| `openTag`/`open` | 段内是否有该字段 | 同上 |
| 图鉴计数 | `codex.ts` 顶层 `id/name/no/stage/ref` 解析，`ref` 按 `/` 拆开计次 | `Select-String src/data/codex.ts -Pattern "ref: '"` |
| 武装计数 | `arms.ts` 四缩进 `id: '<id>', kind: '<系谱>', name: '<名>'` | `Select-String src/data/arms.ts -Pattern "^    id: '"` |
| 日志计数 | `log.ts` 的 `id: 'lg-\d+'` | `Select-String src/data/log.ts -Pattern "id: 'lg-"` |
| 立绘到位 | `public/charimg/<id>.{webp,png,jpg}` 与 `<id>-face.*` 是否存在 | `Get-ChildItem public/charimg` |
| CG 到位 | `public/cg` 递归下的图片文件 | `Get-ChildItem public/cg -Recurse -File` |
| 原文密度 | `.canon/<卷>` 里「正文类」文件（序章/第N话/尾声）字节数之和，**排除** cover/artwork/color/Section/特典/解说 | 见 §1 附脚本 |
| 正文对齐 | `timeline.phase` 里 `「…」` 括起的章题 vs `.canon/<卷>` 文件名里 `『…』` 括起的章题 | 同上 |

### 1.1 判定档位

- **已覆盖**：该卷该维度有独立条目且带卷内定位（章题/编号/引用），可直接上屏。
- **部分**：有条目但缺关键字段（无逐字引文、无名册、无出处卷），或覆盖率 < 2/3。
- **缺失**：该卷该维度 0 条，或全局根本没有这张表/这类素材。

### 1.2 附：复现用最小脚本（Node，只读）

```js
// node check-coverage.mjs   （放在仓库外任意位置运行，只读不写）
import fs from 'node:fs'
const R = 'D:/游戏开发/', V = ['v1','v2','v3','v4','v5','v6','s1'], rd = p => fs.readFileSync(R+p,'utf8')
const tl = rd('src/data/timeline.ts'), sc = rd('src/data/scenes.ts')
const evs = [...tl.matchAll(/id: '((?:v\d|s1)-\d+)'/g)].map(m=>m[1])
const sceneIds = [...sc.matchAll(/\n  '((?:v\d|s1)-\d+)': \{/g)].map(m=>m[1])
const flat = V.map(v => fs.readdirSync(R+'.canon/'+v).filter(f=>f.endsWith('.txt'))
  .map(f=>rd('.canon/'+v+'/'+f)).join('\n')).join('\n')
  .replace(/[\s「」『』“”"'，。、！？…—·]/g,'')
const verbatim = [...sc.matchAll(/\n  '((?:v\d|s1)-\d+)': \{([\s\S]*?)\n  \},/g)]
  .map(([,id,b]) => { const q = b.match(/quote: '([^']+)'/); return { id, has: !!q, ok: !!q && flat.includes(q[1].replace(/[\s「」『』“”"'，。、！？…—·]/g,'')) } })
console.log('events', evs.length, 'scenes', sceneIds.length,
  'quote', verbatim.filter(x=>x.has).length, 'verbatim', verbatim.filter(x=>x.ok).length)
```
