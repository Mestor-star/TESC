## 1. 修掉的缺陷

### 1.1 事件收束后「进入下一事件」切视图就消失（P0，主人点名）
- 根因：`concluded` / `pendingBattle` 是 `Plot` 的组件 state，而视图按 `case` 换 lazy chunk，切走即卸载。
- 修法：新增 `src/lib/plotpending.ts`（键 `zts-plot-pending:v1`，白名单重建 + 过期校验），所有清理点走同一个门。归档、续话、回退、重写、清空会话等 8 条路都会同步清盘，不留幽灵按钮。
- 回归：冒烟新增 `C2c 收束栏跨视图保留`（切「低语者日志」再切回，按钮与文案逐字一致）。

### 1.2 名字中点混用（U+30FB / U+00B7 / U+2027 / U+FF65）导致的一连串漏记
- 真影响：任务卡「推荐名单」解析不全 → 高危任务实际少上人（危险度 9/10 偏难的**结构性主因**）；台词说话人认不出；群聊「谁托付的」认不出；世界书/图鉴条目按名字匹配失效；正文出场识别漏记。
- 修法：全仓收成一把尺 `src/lib/namekey.ts`（NFKC + 去空白 + 中点统一），接入 derive / dialogue / Tavern / codex / sms / Terminal。
- 等价性证明：57 个 offtext 文件 52018 行 → 26009 段，改前改后**逐段 JSON 全等**；424 条登记名写法对照里仅 8 条变化，全部是「旧 narr → 新 say」，反向 0 条。

### 1.3 同调削破绽会把敌体削成「永久待凝」
- `fireSync` 把 `guardPts` 削到 0 时不置 `broken` / `guardMend`，而 `stripGuard` 见 0 直接返回 → 那一层永远凝不回来。
- 修法：同调**下限留 1 点**（不抢「破防」那一手），另加重凝拍里的僵死态自愈（写日志，不静默修）。

### 1.4 读档 / 重置串档
- `applySnapshot` 只换 RUN/PLOT/TAVERN，约会名册、自建群、未读角标、短信托付账、主动来信节拍账全部残留；IndexedDB `zts-battle`（军需/体力/战报）**读档完全没碰**。
- 修法：`RUN_STATE_KEYS` 一份清单两条路径共用；`zts-battle` 走 `resetBattleToInitial()`（与重置同一个函数）；`applySnapshot` 变 async，读档入口先 await 再重挂。

### 1.5 手机短信输入框够不着（键盘一弹彻底打不了字）
- 手机档改成定高链：页头按内容 → `.wrap flex:1; min-height:0` → 消息列表唯一滚动 → 输入框固定尾行；键盘档（≤560 高）页头与会话列表让开。
- 实测 390×844 输入带 699→764（视口 844）；390×420（模拟键盘）275→340；桌面 1440×900 **改前改后逐像素一致**。

### 1.6 其它
- 浮层不吃 Esc（存读档 / 变量面板）→ 已修，且**不吞输入框里的 Esc**，关闭后焦点还给触发按钮。
- 总览三枚图标钮 23×19 → 24×24（图标仍 13px）。
- 出场识别从 3 条硬编码全名 → 从数据表推导的别名表（含「乃梦/义人/次郎」这类简称），三道闸门防误记；真数据命中 1 段 → 3 段，5 条抽查全为真出场。

## 2. 战斗系统

- **机制**：连携点（破绽/尽碎/击倒进账 → 满格放「同调」）、可读连携条件表、敌方 AI（集火/治疗/换招/危机应对，重手频率仍是 engine 掷的 0.35）、首领狂暴 + 破防窗口、战果数据侧。
- **平衡**：危险度 5 从「100% 没张力」降到 95%；9/10 从 64/61（bugfix 后偏易）拉回 52/52；1–4 保持 100%；卡死 0。为做到这一点把敌体数量曲线改成 5 档起 3 只，并拆出 `bossTierStage=6`（档位线）与 `ultStage=8`（终结技线）。
- **作战屏**：连携点条 / 条件表 / 敌方意图 / 狂暴与「两种零」（破防窗口 vs 破绽归零待凝）/ 同调·狂暴全景行；**回合制键盘操作**（方向键移动、Z 确定、X 返回、C 角色介绍、F2 特效预览台）；选目标改成**角色卡**（头像/名字/等级/血量/破防层数/buff）；演出强度菜单可切「标准/减弱」（跟随系统 reduced-motion）。
- **攻击特效**：按角色/招式做的数据驱动动效（斩/射/爆/雷/重力/治愈/支援/破防各成一族，10 手已点名），原文依据在 `src/views/BattleFx.notes.md`（每条摘句带 offtext 文件行号）。镜头语言按主人要求收回：无整屏推拉、震屏 ≤1px/2 帧、无全屏白闪。
- **战果 → 主线**：`plotTieInOf` 真正接上（幂等键 `battle.settled`），战况进观测记录与记忆视图；导演提示词新增「最近一场 · 战况读数」，`phases>1` 时明写「对面已经换过形态，别再照第一形态写」。
