# public/cg/ · 插图素材清单

这个目录里住着**两样东西**，摆的地方不一样，别当成一回事：

| | 是什么 | 摆在哪 | 谁来选 |
| --- | --- | --- | --- |
| **CG**（`cg-date-*`） | 画出来的那一张场景图 | 见面约会页顶部 | **由上下文自动放置** —— 导演按这一场的进展点名，落进 `world.cg[约会id]` |
| **立绘**（`cg-datewear-*`、`cg-intim-*`） | 人长什么样 | 见面页右栏（约会常服）/ **角色档案**（私密档案背面左栏） | 写死的文件名，不走点名 |

把图按下面的名字丢进这个目录，对应的版位**立刻点亮**，不用改任何代码。
没补图的槽位只留一行「CG 待补 · 该补的文件名」，**不占版位** —— 所以哪一页都不是
一块空洞，**放一张亮一张**，也不存在缺图报错。

> 本文件与同目录的图片均随仓库分发。
>
> **想直接对着单子收图 / 画图**：看同目录的 [清单.md](清单.md) —— 那是
> `node scripts/cglist.mjs` 导出的全部槽位表（每个槽位的文件名 + 有没有补，CG 那一档还带一行说明），
> 补一张重跑一次就能当进度表看。

## 命名规则

| 文件名 | 用途 |
| --- | --- |
| `<cgId>.webp` / `<cgId>.png` / `<cgId>.jpg` | 一张 CG，铺满该槽位（`object-fit: cover`） |

- 扩展名按 `webp` → `png` → `jpg` 依次试，三种都认，备一种即可（webp 体积约为 png 的 1/3）。
- 换图只要**换个更靠前的扩展名**就能盖掉旧的：想替掉现成的 `.jpg`，丢一个同名的 `.webp` 进去即可，不必先删旧文件。
- 三种全 404 时回退成一行小字，直接写出该补到哪个文件名（不占版位）。

## 槽位从哪来（两处）

| 槽位 | 是哪一种 | 登记在 | 什么时候上屏 |
| --- | --- | --- | --- |
| **见面约会** | CG | `src/lib/rendezvous.ts` 的 `DATE_CG` / `DATE_CG_INTIMATE` | 约会页会话流顶部；**导演点名了才摆**（落进 `world.cg[约会id]`） |
| **约会常服立绘** | 立绘 | 写死的文件名 `cg-datewear-<角色id>`（`dateWearId`） | 见面页右栏；**她在这场里就摆**，不等点名 |
| **私密档案立绘** | 立绘 | 写死的文件名 `cg-intim-<角色id>` | 档案卡背面左栏，翻到私密档案就摆 |

两条**立绘**都是「一人一张、id 由角色 id 现算」—— 不登记进任何候选清单，
所以往那两族里加人不是「加一行登记」，而是那人进没进名单（`src/data/intimate.ts`）。

**不是「原文里的一处插图」就登记一个槽位。** 主线剧情那一侧**没有** CG 位 ——
事件段（`src/data/scenes.ts`）一个字都不记图，上屏全是正文。

### 约会常服立绘（`cg-datewear-<角色id>`）

**一人一张，她约会那天穿的常服** —— 摆进见面页**右栏**（在线推演那一栏的右边），
「这一场在场的人」一节里每人一张同等大：

| 文件名 | 对应角色 |
| --- | --- |
| `cg-datewear-<charId>.webp` / `.png` / `.jpg` | 例：`cg-datewear-hikari.webp`（恋兔光）、`cg-datewear-luna.webp`（露娜） |

- **它不是 CG。** 不登记进任何候选清单，导演点不到它，也不落 `world.cg` ——
  立绘跟着人走：她在这一场里，那一栏就该有她的脸（见 `components/DateSide.tsx`）。
- `charId` 就是那份名单的键（`src/data/intimate.ts`，共 19 位女角色）——
  与私密档案立绘同一份名单，两位立绘是**同一个人的两张画**。
- 缺图时**不占版位**，只塌成一行「待补」并写明该补到哪个文件名。
- 别跟约会那批（`cg-date-*`）、私密立绘（`cg-intim-*`）撞名。

### 见面约会（`DATE_CG` / `DATE_CG_INTIMATE`）

- 前三张（街道 / 夜里的高处 / 房间门口）哪一场都进候选；
- 私密那几张**只有这一场走到私密那一档**才进候选 —— 所以它们可以画得比前面三张更直给；
- 再往下还有一种**认人**的（`CgRef.cast`）：除了档位，**还要名单上那一位在场**
  （主位与同场的都算，见 `rvAllIds`）。只属于某一个人的那张 —— 例
  `cg-date-intim-luna-oral`（`cast: ['luna']`）—— **缺了人就不进候选**，
  也就不会在没有她的场面里顶出来。
- 最后还有一种**认节拍**的（`CgRef.needs`）：除了档位与人在场，**还要这一场先走到那一步**。
  节拍登记在 `src/lib/rendezvous.ts` 的 `DATE_BEATS`（每条一句话说清「走到哪一步才算」），
  例：`cg-date-shop-luna` 带 `needs: 'outfit-tryon'` —— **买完衣服、试穿上了**才进候选。
  节拍记在**这一场自己**身上（`Rendezvous.beats`），所以**散场即归零**，下一场得重新走到。
- 导演从合并后的清单里点名，落进 `world.cg[约会id]`（见 `src/lib/rendezvous.ts` 的
  `dateCgPalette` 与 `src/components/DateLane.tsx`）。**点名前一张都不摆** ——
  一进线程就顶一张图，把开场那两句挤到屏幕外，不划算。
- **认不认这个 id 由 `dateCgPalette` 说了算**：档位不到、该在场的人不在、那一步还没走到，
  或者压根是模型编出来的 id，一律当没点 —— 那张图也不摆（上游 `world.cg` 里存着什么不算数）。
- 三道窄法是**叠着**的（`kind` → `cast` → `needs`），不是互相替代：**没写的那一道等于不管**，
  所以街景那三张谁都能点。

### 私密档案立绘（档案卡背面）

档案卡翻到背面（角色档案 → 私密档案，只对女角色生效、羁绊 70 以上）时，
左栏是一幅竖立的立绘位 —— **与正面那一栏同一套版式**（铺满整栏、右缘渐隐进档案底色、
底部一条说明带），翻面时版面不跳。文件名按角色 id 走：

| 文件名 | 对应角色 |
| --- | --- |
| `cg-intim-<charId>.webp` / `.png` / `.jpg` | 例：`cg-intim-hikari.webp`（恋兔光）、`cg-intim-luna.webp`（露娜） |

- `charId` 就是档案角色 id（见 `src/data/intimate.ts` 的键，共 19 位女角色）。
- 版位是**左栏那一根窄高条**（`minmax(240px, 1fr)` 的一栏，高 `min(84vh, 760px)` 减掉底部
  说明带 ≈ 620 px），算下来**约 1 : 2**。按 `contain` 摆 —— 整身要完整看得见，
  **画得比 1:2 更方也不会被裁**，只是两侧留空；想铺满就照 1:2 竖构图来。
- 缺图时**不占这一栏**，只在栏底留一行「待补」并写明该补到哪个文件名
  （`components/CgSlot.tsx`），**放一张亮一张**，不用改任何代码。

## 出图规格

**不在仓库里。** 画风口径、尺寸、用哪套工具，是作者自己的活儿 —— 这一页只写
「图该叫什么名字、摆在哪、别把版式撑坏」，出图规格另有出处。

非要一个数的话，看代码里的两处版位就够了（尺寸由它们定，不在文档里复述）：

| 槽位 | 实际版位 | 在哪 |
| --- | --- | --- |
| 见面约会那张 | 宽 520 px 封顶、**3 : 2**、`cover` 裁 | `components/DateLane.tsx` 的 `ratio="3 / 2"` + `.threadCg` |
| 约会常服立绘 | 见面页右栏、约 **2 : 3**、`contain` 摆 | `components/DateSide.tsx` 的 `ratio="2 / 3" fit="contain"` + 右栏宽度 |
| 私密档案立绘 | 左栏、约 **1 : 2**、`contain` 摆 | `views/Archive.tsx` 的 `fill fit="contain"` + `.intimBackArt` |

两条通用的：**jpg 没有透明通道**，透明区会露出组件自带的深色底 —— 铺满那几张用 jpg
更合适，立绘想干净就用 webp / png；**webp 同画质约为 png 的 1/3**，能压就压。

## 小抄

- **改了图不生效？** `public/` 下的文件不带哈希，浏览器可能吃旧缓存 —— `Ctrl+F5`，或换个文件名。
- **控制台一堆 404？** 那是候选链在逐个试（`webp` → `png` → `jpg`）。只备一种扩展名时想消掉，
  把它挪到 `src/lib/cg.ts` 的 `EXTS` 最前面即可。
- **头像**不放这里，放 `public/charimg/`（见那边的 README）。立绘分三处：**定妆立绘**
  （名单页 / 档案正面那一张，按 `avatarId`）在 **`charimg`**；**约会常服立绘**
  （`cg-datewear-*`，见面页右栏）与**私密档案立绘**（`cg-intim-*`，档案背面左栏）
  在**这里** —— 同一个人的几张画，各走各的目录，互不覆盖（见 `src/lib/cg.ts` 文件头）。
