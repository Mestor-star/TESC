# public/cg/ · 场景 CG 素材清单

把图按下面的名字丢进这个目录，Saga 页**立刻点亮**，不用改任何代码。
没补图的槽位显示「待补」虚线空框，所以**放一张亮一张**，也不存在缺图报错。

> 本文件与同目录的图片均随仓库分发。

## 命名规则

| 文件名 | 用途 |
| --- | --- |
| `<cgId>.webp` / `<cgId>.png` / `<cgId>.jpg` | 场景 CG，铺满该槽位（`object-fit: cover`） |

- 扩展名按 `webp` → `png` → `jpg` 依次试，三种都认，备一种即可（webp 体积约为 png 的 1/3）。
- 换图只要**换个更靠前的扩展名**就能盖掉旧的：想替掉现成的 `.jpg`，丢一个同名的 `.webp` 进去即可，不必先删旧文件。
- 全 404 时回退虚线空框，框里会直接写出该补到哪个文件名。

## 槽位从哪来

**一个槽位 = 原文里的一处插图位置**（卷首彩页、话中插画）。不自己编图位：
`src/data/scenes.ts` 的 `cg` 里只登记**原文确有的那张图**，`note` 写清它画的是哪个瞬间。

```ts
'v1-1': {
  openTag: '— 第1卷 · 序章 『船与影』',
  ...
  // 一项 = 原文那一处的插图；note 是给导演判断「走到没走到这一幕」的一句话
  cg: [{ id: 'v1-1-p01', note: '…' }],
},
```

- 一项 = 一个 `<cgId>` = 这个目录下的一个文件名，**按原文插图的出现顺序排**。
- 想加槽位就往数组里加 id，想撤就删掉 id —— 那个文件留着不影响别处。

## 通用图位（不属于某一段的）

比如据点全景、终末降临的空镜、某角色的定妆半身 —— 这些不用往每一段里各抄一份，
登记在 **`src/data/cgs.ts` 的 `CG_POOL`** 里，全部事件段共用：

```ts
// src/data/cgs.ts
export const CG_POOL: CgRef[] = [
  { id: 'cg-committee-hall', note: '委员会总部大厅 · 长长的圆桌与窗外的苍色天光' },
  { id: 'cg-hikari-stand',   note: '恋兔光的定妆半身', cast: ['hikari'] },
]
```

两条规矩：

- **只在导演点名时才出，不参与兜底。** 本段登记的图位没被点名时会摆头一张；通用池不会 ——
  否则每一段一铺开都先冒出一张跟此刻无关的通用图。
- **带 `cast` 的位，只有本段出场阵容里有其中之一才进候选。** 上例里 `cg-hikari-stand`
  只在恋兔光在场的段里出现，不会跑进没有她的场面。不带 `cast` 的哪一段都能用。

id 要全局唯一，别跟各段自己那批撞名。

## 按上下文选图

CG 可以跟着**主角做过什么**变，而不是每段钉死一张。给一项挂上 `when` 即可：

```ts
'v1-2': {
  cgMode: 'one',              // 只摆最后一条成立的（缺省 'all'：成立的都摆）
  cg: [
    { id: 'v1-2-gate', note: '转生之门 · 敞开' },                      // 无条件 → 兜底
    { id: 'v1-2-refuse', when: { pick: [['v1-2', 'refuse']] },  note: '他收回了手' },
    { id: 'v1-2-take',   when: { pick: [['v1-2', 'take']] },    note: '那一瞬的动摇' },
  ],
},
```

- `when` 里的各项是**与**关系，全成立才摆；不写 `when` 就是恒成立，通常当兜底放最前。
- 能拿来判断的三样（判据只看主角的行为，不看读到第几段）：
  | 键 | 含义 | 例子 |
  | --- | --- | --- |
  | `pick` | 某段的抉择结果 | `pick: [['v1-9', 'refuse']]` |
  | `flag` | 推进/抉择落下的世界标记 | `flag: [['v1-2-take', true]]` |
  | `bond` | 好感门槛，写法同事件的 `gate` | `bond: [{ char: 'luna', value: 70 }]` |
- **数组顺序 = 优先级**（从泛到专）。`cgMode: 'one'` 时取最后一条成立的，
  所以兜底放最前、越具体的越靠后；`'all'` 时成立的全部横排摆出。
- 一条都不成立 → 这一格整块不出现（与「位子成立但素材没到」不同，后者会摆「待补」框）。
- `note` 是图注，可选；不写就在占位框里显示 id。

判断逻辑在 `src/lib/cg.ts` 的 `selectCg()` / `cgWhenHolds()` —— 纯函数，好改也好测。

## 建议规格

| 槽位 | 显示 | 出图建议 |
| --- | --- | --- |
| 场景 CG（Saga 当前事件卡） | 宽约 210–520 px，16:9 | **1280×720 或 1920×1080**，横构图。按 `cover` 裁，主体别贴边 |

- 单张压在 **300 KB** 以内。
- jpg 没有透明通道，透明区会露出组件自带的深色底 —— 需要透明就用 webp / png（CG 位一般铺满，用 jpg 更合适）。

批量处理参考（ImageMagick）：

```bash
# 统一转 webp，宽度封顶 1600
magick mogrify -resize 1600x -format webp -quality 82 *.png
```

## 小抄

- **改了图不生效？** `public/` 下的文件不带哈希，浏览器可能吃旧缓存 —— `Ctrl+F5`，或换个文件名。
- **控制台一堆 404？** 那是候选链在逐个试（`webp` → `png` → `jpg`）。只备一种扩展名时想消掉，
  把它挪到 `src/lib/cg.ts` 的 `EXTS` 最前面即可。
- **角色头像 / 立绘**不放这里，放 `public/charimg/`（见那边的 README）。
