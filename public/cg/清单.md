# 插图补图清单（生成物 · 别手改）

两种东西：**CG**（见面约会那一档，由上下文自动放置）与**立绘**（约会常服 · 私密档案立绘，一人一张、文件名写死，摆进见面页右栏与角色档案）。

> 这份清单由 `node scripts/cglist.mjs` 从 `src/data/intimate.ts`、`src/lib/rendezvous.ts` 导出。**改槽位要改那两处再重跑**，手改这里下一次重跑就没了。

## 怎么补

1. 图放进本目录（`public/cg/`），文件名 = 下表「文件名」那一列，扩展名按 `webp` → `png` → `jpg` 依次试，备一种即可（webp 体积最小）。
2. **不用改任何代码**：放一张亮一张；没图的槽位只留一行小字，写着该补的文件名（不占版位）。
3. 版位形状由代码定（**约会 CG 3:2 `cover`；约会常服约 2:3 `contain`；私密立绘约 1:2 `contain`**），出图规格不随仓库走 —— 详细说明见同目录 `README.md`。
4. 改了图不生效：`Ctrl+F5`（`public/` 下的文件不带扩展名哈希，浏览器会吃旧缓存）。

**当前进度：1 / 42 已补（还缺 41 张）** —— ✅ = 目录里已有图，⬜ = 待补。

## 三、见面约会的图位（`src/lib/rendezvous.ts`）

版位 **3 : 2 横构图**（宽 520 px 封顶，按 `cover` 裁，主体别贴边）。
前三张哪一场都进候选；私密那几张**只有这一场走到私密那一档**才进候选 —— 所以它们可以画得比前面三张更直给。
